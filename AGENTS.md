1. Read **`CLAUDE.md`** first. It is the director's playbook: working style with Vansh, vocabulary, rules, workflow, gotchas.
2. Read **`docs/ARCHITECTURE.mmd`** (Mermaid) for the map of the repo and both pipelines.
3. The portable skill is **`.claude/skills/motion-engine/SKILL.md`**. It is the same instructions in a compact form, usable from any device or cloud session.
4. Pick the mode:
   - **Mode A**: a motion-graphics SaaS promo in Remotion. Start in `src/projects/<client>/`, following `docs/NEW_PROJECT.md`.
   - **Mode B**: a 3D short film with realistic actors in Blender. Start in `film3d/README.md` and use `film3d/make_film.sh`.
5. Non-negotiables:
   - No paid tools or assets.
   - Real brand data only; never invent stats.
   - Frame-check stills before any full render.
   - Deliver with a density scorecard.
   - State plainly what is a recreation versus real.
