# WebEpex v2 — client revision plan

## Client notes → rules
| Note | Rule for v2 |
|---|---|
| Improve fonts | Headlines in **Inter Tight 800, UPPERCASE, 140–260 px**. Instrument Serif italic only for 1 accent word per line. No light/thin weights. |
| More contrast, no soft colours | Only two backgrounds: **espresso-black #0A0705** and **cream #F5F0E8**. Text = the other one. Gold **#C9A77A** only on black (accent words, stamps). No greys, glows, vignettes, grain, translucent cards or gradients. |
| Remove long em dashes | No "—" or "–" anywhere. Ranges written "2 TO 5×", "7 TO 10 DAYS", "35 TO 40%". |
| Keep everything centred | One focal point per beat, dead centre. No side columns, corner labels or chapter HUD. |
| Movements fast, fast cuts | Hard cuts on the music beat (103.4 BPM → a beat every 0.58 s; cuts every 1–2 beats). Entries in 4–8 frames. |
| Big text | Every beat = one short phrase, huge, centred. |
| Don't fill space, focus on where the eye is | Empty frame is fine. Each beat answers "what is the viewer looking at right now?" |
| Funnel + laptop look bad | **Removed.** Replaced with flat, full-frame real screenshots and typographic beats. |
| 3D logo looks bad | **Removed.** New 2D logo slam (below). |
| More innovative | New moves: center-lock word stack, invert flash on downbeats, screenshots seen *through* giant letters, 3-frame rapid montage, stamp slams, draining revenue meter, card-deal pile. |
